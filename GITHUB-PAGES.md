# Triển khai trên GitHub Pages

Không cần Netlify hoặc build framework.

1. Nếu dùng GitHub Free: vào Settings → General → Danger Zone → Change repository visibility → Public. Toàn bộ mã nguồn và tệp trong kho sẽ công khai. Nếu gói tài khoản hỗ trợ Pages cho kho Private, có thể giữ Private; website xuất bản vẫn cần truy cập công khai để giám khảo xem.
2. Vào Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, thư mục / (root), nhấn Save.
5. Chờ GitHub triển khai và dùng URL được trang Pages xác nhận. URL dự kiến: https://vuthanhthuy257-star.github.io/phong-tranh-6b/
6. Kiểm tra bằng cửa sổ riêng tư, điện thoại và máy tính. Chỉ tạo QR khi URL thực sự hoạt động.

Cập nhật tranh bằng images/, videos/ và js/artworks.js trên cùng nhánh main. GitHub Pages sẽ triển khai lại, địa chỉ giữ nguyên nếu không đổi tên tài khoản/kho. File .nojekyll cho phép phục vụ HTML/CSS/JS trực tiếp.

Ảnh/video mẫu đều là minh họa, không phải tranh học sinh thật. Chưa có kết quả kiểm thử trình duyệt thành công trong môi trường xây dựng; xem BAO-CAO-KIEM-THU.md.

GitHub Pages cũng có hạn mức về kích thước website, băng thông và triển khai. Kiểm tra tài liệu/chính sách hiện hành trước khi tải video lớn; chỉ tải từng video đang xem không có nghĩa băng thông không giới hạn.
